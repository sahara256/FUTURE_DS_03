## Task 3: Social Media Sentiment Analysis

### Objective
Analyze public sentiment from social media data to understand user opinions and engagement patterns.

### Tools Used
- Power BI
- DAX
- Power Query

### Dataset
- Social media posts containing text, sentiment labels, engagement metrics, and platform information.

### Key Metrics
- Total Posts
- Positive, Neutral, Negative Sentiment %
- Engagement (Likes / Retweets)

### Key Insights
- Positive sentiment dominates overall social media posts.
- Neutral sentiment reflects informational discussions.
- Negative sentiment is comparatively lower but consistent.
- Sentiment trends vary across platforms and regions.
